# MXW01 Print — mobiele GitHub Pages versie

Deze eenvoudige interface gebruikt de `mxw01-thermal-printer` browser-library en Web Bluetooth.
Het doel is een mobiele bediening voor Android/Chrome: foto kiezen, preview, verbinden en printen.

## GitHub Pages
1. Maak een nieuwe publieke GitHub repository.
2. Upload `index.html` en `manifest.json`.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Open de gegenereerde `https://<gebruikersnaam>.github.io/<repo>/` URL in Chrome.

## Let op
Web Bluetooth vereist Chrome/Edge en HTTPS. Sluit andere apps die met de printer verbonden zijn.
